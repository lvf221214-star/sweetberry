# Sweet Berry Client (Fabric 1.21.4)

Build:   ./gradlew build        (Gradle-Wrapper vorher mit `gradle wrapper` erzeugen, oder in IntelliJ importieren)
Output:  build/libs/sweet-berry-client-1.0.0.jar  -> in den mods-Ordner (Fabric Loader + Fabric API nötig)

Steuerung:
  Right Shift        ClickGUI öffnen
  Linksklick         Modul an/aus
  Rechtsklick        Einstellungen aufklappen
Kategorie: Donut   |   Modul: Chunk Finder (Sensitivity, Simulation Distance, Render, Chat Notify)
